# DSH Desktop v0.8.3

本轮是**性能与响应修复**：退出从 5–8 秒降到约 0.1 秒，托盘左键点图标也能唤起窗口了。

## 修复

- **退出快了一个数量级（5–8s → 105ms）**：桥接插件改为自持 HTTP 监听句柄并 `unref`，不再把 harness 进程钉住。
  根因是官方 harness 的退出依赖事件循环自然 drain，而桥接的监听 socket 是 ref 句柄 —— 实测 Host 收到 shutdown
  后 60 秒仍不退出、端口仍在监听，壳只能等兜底超时才 SIGKILL。修复后同一场景约 2 秒干净退出（exit code 0）。
- **点「退出」不再像没反应**：点下去 4ms 内托盘图标与窗口立即消失；退出流程始终拦截二次 `before-quit`，
  不会再在 Host 停完之前把进程收掉而留下孤儿 Host（孤儿会占住 19387，让下次启动变慢）。
- **托盘左键单击/双击图标 = 显示工作台**（之前只注册了右键菜单，点图标没反应）。
- **菜单不再被频繁重建**：托盘菜单加了内容指纹，只有可见内容变化才重建。Windows 上菜单开着时被替换会丢点击，
  这正是「有时退出要点两次」的来源。
- **重启 Harness 不再 7s 超时强杀**（旧进程现在能干净退出），也就不会留下占资源的旧进程让下一次启动顿挫。
- 启动路径加了常驻分段计时日志（`[perf]`）：壳侧只占约 0.25s，加载页 0.25s 出现，工作台 3.0s 可用
  （其中 2.4s 是官方组合树引导，与本壳无关）。

## 备注

- 随包运行时：`@deepseek-ai/dsh` 0.1.6-alpha.2、`dsh-desktop-bridge` 0.4.1、`dsh-desktop-host` 0.1.6-alpha.2。
- 应用内「检查更新」即可自动下载安装；会话与设置不受影响。
